# NisheshChauhan_Task(19)

## Summary
This assignment is a responsive laundry and dry-cleaning service booking page. It lets users browse available services, add them to a cart, see the total amount, and submit a booking request with their details.

## What it does?
- Displays a list of cleaning and laundry services with images, names, and prices.
- Allows users to skip or add the current service to the cart.
- Shows added services in a table with their individual prices and the total amount.
- Validates the booking form for full name, email, and phone number before submission.
- Displays success or error messages when booking is attempted.
- Lets the user reload the page using the top-right logout-style icon.

## How to run??
- Open the index.html file in your browser to see the assignment.
- or go through the deployed GitHub link.
