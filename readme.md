# NisheshChauhan_Task(20)

## Summary

A single-page responsive "Laundry Services" booking UI built with HTML, CSS and vanilla JavaScript. It demonstrates a services catalog with icons and prices, an interactive add-to-cart flow, a booking form with validation, and client-side EmailJS integration for sending booking and subscription emails.

## What it does?
- Shows a services menu (Dry Cleaning, Wash & Fold, Ironing, Stain Removal, etc.) with icons and prices.
- Lets users add or remove services to a cart and displays the total amount.
- Validates user input (name, email, phone) before enabling booking.
- Sends booking and newsletter emails via EmailJS (client-side integration).
- Provides navigation to sections, success/error feedback, and basic responsive layout.

## How to run??
- Open the index.html file in your browser to see the assignment.
- or go through the deployed GitHub link.
